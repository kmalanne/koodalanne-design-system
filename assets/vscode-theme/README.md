# koodalanne — Neon Precision

A premium synthwave dark theme from the **koodalanne** design system. Midnight surfaces with neon pink and cyan accents, tuned for long, focused coding sessions.

## Palette

| Role          | Color     |
| ------------- | --------- |
| Background    | `#111218` |
| Foreground    | `#ececee` |
| Neon pink     | `#f890e7` |
| Neon cyan     | `#0bd3d3` |
| Violet        | `#7a5cff` |

## Install

### From a `.vsix`

```bash
npm install -g @vscode/vsce
vsce package
code --install-extension koodalanne-neon-precision-1.0.0.vsix
```

### Local development

Symlink the folder into your extensions directory and reload:

```bash
ln -s "$(pwd)" ~/.vscode/extensions/koodalanne-neon-precision
```

## Activate

Open the Command Palette (`Cmd+K Cmd+T` / `Ctrl+K Ctrl+T`) → **Preferences: Color Theme** → select **koodalanne — Neon Precision**.
