# koodalanne — The Companion

> Part 8 of the Brand Bible. The recurring visual signature of the brand: **one
> gravel bike, always drawn the same** — like Porsche's 911 silhouette. Cycling
> is a genuine part of who's behind koodalanne, so the mark is authentic rather
> than decorative. Assets live in
> [`design-system/mascot/`](../design-system/mascot/).

---

## Why a bike (and why not a character)

The logo already owns *retro* (Press Start 2P). The companion deliberately goes
the other way — **modern, minimal, vector** — for contrast. No mascot creature,
no anthropomorphism, nothing cute. Just a clean, confident object that quietly
signals the person behind the work: calm, curious, always moving.

## The family

| Asset | File | Use |
| --- | --- | --- |
| Primary | `bike.svg` | Dark-first: light outline + pink/cyan accents. |
| Light surface | `bike-ink.svg` | Ink outline for documents, invoices, stickers on light. |
| One-color | `bike-mono.svg` | Inherits `currentColor` — stamps, embroidery, single-ink print. |
| App icon | `bike-tile.svg` | Ink tile + cyan hairline (512) — avatars, stickers, social. |

Accents are fixed: **cyan** saddle + drop bar, **pink** hubs. One pink, one cyan
— same rule as everything else.

---

## Rules

- **Always the same bike.** Never redraw it per context; consistency is the point.
- **Quiet, never loud.** It belongs in a README, a 404, a loading state, a
  sticker, a slide corner — **never** the website hero or competing with the CTA.
- **One accent pair.** Cyan + pink only; never recolor the frame.
- **Keep it minimal.** Don't add a rider, road, sunset or scenery to the mark
  itself — the bike alone is the signature.
- **Scales down.** Legible from 16px up; below that, prefer the monogram.

## Where it shows up

GitHub README · 404 page · loading states · slide corners · stickers ·
email signature flourish · the occasional easter egg. Over time people associate
that one bike with koodalanne — a signature, not a logo.
